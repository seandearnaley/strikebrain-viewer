# Milestone 8: the window — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One title bar over both panes, an explorer that hides, Back and Forward through what the stage showed, and a file opened on its own as a top-level row whose folder is never read.

**Architecture:** The root view (`AppView`) draws the Kit's `TitleBar` above the split, built by a function in a new `title_bar.rs` from the `AppState` and the explorer's width. Every command the bar, the menus and the keys offer is a GPUI action handled at the root view. The history is the Kit's `History<Step>` inside `AppState` (`state/history.rs`). A file opened on its own is one more top-level entry of the joined tree: the engine scans a file as a one-node tree, and a folder's scan takes such a file in as it takes in folders. The app's folder machinery (scan, watch, remove, take in) then carries file rows unchanged.

**Tech stack:** Rust 1.100.0, `gpui-kit =0.10.0` (GPUI `gpui-pre 0.3.12`, `gpui-component 0.10.0`, `gpui-base 0.10.0`), `notify` 9, nextest.

**Spec:** `docs/superpowers/specs/2026-11-22-strikebrain-viewer-design.md`, section "Milestone 8: the window" (line 468 on). Read it before each task.

```rust
//! The window's title bar: the Kit's `TitleBar`, one row across the top of
//! the window above both panes, in place of the system's title bar and the
//! explorer's toolbar.
//!
//! Its part over the explorer is exactly as wide as the explorer, so the
//! rule that ends it continues the split's divider: the traffic lights'
//! room, then Add Folder and More at its right end, and the scan's progress
//! along its bottom edge. Its part over the stage holds the stage's title
//! and Present. Its buttons dispatch the window's actions, which the root
//! view handles, so a button, a menu item and a key run the same code.
//!
//! The Kit pads its bar 80 px on macOS (12 px elsewhere) for the traffic
//! lights; this bar zeroes that padding and keeps the room inside its
//! explorer part, which can then start at the window's edge. In fullscreen
//! no lights show and the Kit pads its inner row `rems(0.75)` itself.

use gpui_kit::component::progress::Progress;

    ActiveTheme as _, Disableable as _, Icon, IconName, Sizable as _, TitleBar, h_flex,

use gpui_kit::{
    Action, Anchor, App, IntoElement, ParentElement as _, Pixels, Role, SharedString,
    Styled as _, TestSupportExt as _, Window, div, prelude::*, px, rems,

/// The traffic lights' room at the bar's left, as the Kit's bar leaves it:
/// none in fullscreen.
fn lead(fullscreen: bool) -> Pixels {
    if fullscreen {
        px(0.)
    } else if cfg!(target_os = "macos") {
        px(80.)
    } else {
        px(12.)
    }
}

/// A 24 px ghost icon button whose tooltip is its accessible name, and
/// which dispatches `action`.
fn command(
    id: &'static str,
    icon: impl Into<Icon>,
    label: &'static str,
    action: impl Action,
) -> Button {
    Button::new(id)
        .ghost()
        .small()
        .icon(icon)
        .tooltip(label)
        .accessibility_label(label)
        .on_click(move |_, window, cx| window.dispatch_action(action.boxed_clone(), cx))
}

/// The bar for `state`. Its part over the explorer is `explorer` wide, or
/// `None` while the explorer is hidden.
pub(crate) fn window_bar(
    state: &AppState,
    explorer: Option<Pixels>,
    window: &Window,
    cx: &App,
) -> TitleBar {
    let fullscreen = window.is_fullscreen();
    // In fullscreen the Kit's inner row starts this far in.
    let inset = if fullscreen {
        rems(0.75).to_pixels(window.rem_size())
    } else {
        px(0.)
    };
    TitleBar::new()
        .bg(cx.theme().background)
        .border_color(cx.theme().border)
        .pl_0()
        .child(explorer_part(
            state,
            explorer.map(|width| width - inset),
            lead(fullscreen),
            cx,
        ))
        .child(stage_part(state, cx))
}

/// The part over the explorer: `width` wide, or only the lights' room
/// while the explorer is hidden.
fn explorer_part(
    state: &AppState,
    width: Option<Pixels>,
    lead: Pixels,
    cx: &App,
) -> impl IntoElement {
    let part = h_flex()
        .id("bar-explorer")
        .test_support()
        .h_full()
        .flex_shrink_0()
        .items_center()
        .gap_1()
        .child(div().w(lead).flex_shrink_0());
    let Some(width) = width else {
        return part;
    };
    let open = !state.is_empty();
    let slow = matches!(state.status(), ScanStatus::Scanning { slow: true });
    let warning = state
        .watch_error()
        .map(|message| SharedString::from(message.to_string()));
    part.w(width)
        .pr_2()
        .relative()
```

```rust
//! The stage's history, for Back and Forward: each file or gallery the
//! stage came to show because of something the person did.
//!
//! A step the person asks for is added and drops the steps ahead of it, as
//! in a browser. Moving with ← and → through the checked files replaces the
//! step, as Photos does, and so does a change the person did not make (a
//! rescan, a folder removed) that moves the file on the stage. A blank
//! stage is not a step. Back and Forward pass over steps that cannot be
//! shown now: a file no longer in the tree, and the gallery while fewer than
//! two files are checked. Kept for the session only.

use std::path::PathBuf;

use gpui_kit::Context;

use super::{AppState, StageView, StateEvent};

/// A step of the stage's history.
#[derive(Clone, Debug, PartialEq, Eq)]
pub(crate) enum Step {
    /// A file in the file view, by its path on disk.
    File(PathBuf),
    /// The gallery.
    Gallery,
}

/// How a change to what the stage shows enters the history.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub(super) enum Record {
    /// Something the person asked to see: a new step.
    Add,
    /// The arrows, or a change the person did not make: the same step.
    Replace,
}

impl AppState {
    /// What the stage shows as a step; `None` while it is blank.
    fn step_now(&self) -> Option<Step> {
        if self.view == StageView::Gallery && self.gallery_len() >= 2 {
            return Some(Step::Gallery);
        }
        let explorer = self.explorer.as_ref()?;
        Some(Step::File(explorer.tree().abs_path(self.current?)))
    }

    /// Enters what the stage shows now into the history, `how` says how. A
    /// blank stage, or the step it already holds, changes nothing.
    pub(super) fn record(&mut self, how: Record) {
        let Some(step) = self.step_now() else {
            return;
        };
        if self.history.current() == Some(&step) {
            return;
        }
        match how {
            Record::Add => self.history.push(step),
            Record::Replace => self.history.replace_current(step),
        }
    }

    /// Whether `step` can be shown now.
    fn can_show(&self, step: &Step) -> bool {
        match step {
            Step::Gallery => self.gallery_len() >= 2,
            Step::File(path) => self.explorer.as_ref().is_some_and(|explorer| {
                let tree = explorer.tree();
                tree.find_abs(path).is_some_and(|id| tree.is_file(id))
            }),
        }
    }

    /// Whether Back has a step to show: one before the current step, or the
    /// current step itself while the stage is blank.
    #[must_use]
    pub fn can_go_back(&self) -> bool {
        let mut steps = self.history.entries().rev();
        let last = steps.next();
        (self.step_now().is_none() && last.is_some_and(|step| self.can_show(step)))
            || steps.any(|step| self.can_show(step))
    }

    /// Whether Forward has a step to show.
    #[must_use]
    pub fn can_go_forward(&self) -> bool {
        self.history
            .forward_entries()
            .any(|step| self.can_show(step))
    }

    /// Back: the nearest earlier step that can be shown; from a blank stage,
    /// the step last shown. Nothing while presenting.
    pub fn go_back(&mut self, cx: &mut Context<Self>) {
        if self.presenting {
            return;
        }
        if self.step_now().is_none()
            && let Some(step) = self.history.current().cloned()
            && self.can_show(&step)
        {
            return self.show_step(step, cx);
        }
        let mut moved = 0;
        while let Some(step) = self.history.back() {
            moved += 1;
            if self.can_show(&step) {
                return self.show_step(step, cx);
            }
        }
        // Nothing to show that way: the history stays where it was.
        for _ in 0..moved {
            self.history.forward();
        }
    }

    /// Forward: the nearest later step that can be shown. Nothing while
    /// presenting.
    pub fn go_forward(&mut self, cx: &mut Context<Self>) {
        if self.presenting {
            return;
        }
        let mut moved = 0;
        while let Some(step) = self.history.forward() {
            moved += 1;
            if self.can_show(&step) {
                return self.show_step(step, cx);
            }
        }
        for _ in 0..moved {
            self.history.back();
        }
    }

    /// Shows `step`, which can be shown, adding no step: a file in the file
    /// view, checked or not; the gallery with `current`'s tile focused.
    fn show_step(&mut self, step: Step, cx: &mut Context<Self>) {
        match step {
            Step::File(path) => {
                let id = self
                    .explorer
                    .as_ref()
                    .and_then(|explorer| explorer.tree().find_abs(&path));
                self.current = id;
                self.view = StageView::File;
                cx.emit(StateEvent::CurrentMoved);
            }
            Step::Gallery => {
                self.view = StageView::Gallery;
                self.set_tile(self.nearest_tile(self.current));
                cx.emit(StateEvent::RevealTile);
            }
        }
        cx.notify();
    }
}
```

```rust
fn resolve_root(root: &Path) -> Result<(PathBuf, Option<u64>), ScanError> {
    let followed = fs::metadata(root).map_err(ScanError::Root)?;
    let file = if followed.is_dir() {
```

```rust
    fn open_file(&mut self, path: PathBuf, cx: &mut Context<Self>) {
        let waits = self.listed(&path).is_some()
            || self
                .folders
                .iter()
                .any(|folder| !folder.shown && folder.holds(&path));
        if waits {
            return;
        }
        if let Some(key) = self
            .folders
            .iter()
            .find(|folder| folder.path == path)
            .map(|folder| folder.key)

        self.next_key += 1;
        let mut entry = Folder::new(key, path, None);
        entry.file = true;
        self.folders.push(entry);
        self.follow(key, cx);
        self.start_scan(key, cx);
```

```rust
pub fn plan_launch(paths: Vec<PathBuf>, saved: Option<Saved>) -> Plan {
    let saved = saved.unwrap_or_default();
    let mut view = saved.view;
    // Files show on their own or in a folder that lists them; they open
    // no folder, so the folders are as they would be without them.
    let (files, folders): (Vec<PathBuf>, Vec<PathBuf>) =
        paths.into_iter().partition(|path| resolve(path).is_file());
    let mut open: Vec<PathBuf> = if folders.is_empty() {
        view.folders.retain(|folder| folder.path.is_dir());
        view.folders
            .iter()
            .map(|folder| folder.path.clone())
            .collect()
    } else {
        let asked: Vec<PathBuf> = folders.iter().map(|path| resolve(path)).collect();
        view.folders.retain(|folder| asked.contains(&folder.path));
        folders
    };
    open.extend(files);
    Plan {
        launch: if open.is_empty() {
            Launch::Empty
        } else {
            Launch::Folders(open)
        },
        view: (!view.folders.is_empty()).then_some(view),
        explorer_width: saved.explorer_width,
        explorer_hidden: saved.explorer_hidden,
        window: saved.window,
    }
}
```
