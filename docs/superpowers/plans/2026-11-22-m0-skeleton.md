# Milestone 0 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Cargo workspace that opens a GPUI window with two resizable panes, passes one headless UI test, and records its build times.

**Architecture:** Two crates. `explorer` is a pure-Rust library with no UI dependency; in this milestone it holds only a placeholder type and one test, so the workspace, lints and test runner are proven. `viewer` is a library plus a thin binary: the library exports the root view so tests drive the same view the binary shows.

**Tech Stack:** Rust 1.100.0 (edition 2024), `gpui-kit =0.10.0` (GPUI snapshot `gpui-pre 0.3.12`), `cargo-nextest`, `bacon`, `cargo-deny`.

**Spec:** `docs/superpowers/specs/2026-11-22-strikebrain-viewer-design.md`

## Global Constraints

- Rust `1.100.0`, edition 2024, pinned in `rust-toolchain.toml` with `rustfmt` and `clippy`.
- `gpui-kit = "=0.10.0"` with feature `syntect`. The dev-dependency adds `test-support` at the same version.
- Application code depends on `gpui-kit` alone for UI. It never lists a GPUI crate directly.
- `explorer` never depends on `gpui-kit`.
- Workspace `resolver = "3"`. Lints: `unsafe_code = "forbid"`; clippy `all` and `pedantic` at warn.
- Check the current docs and source before using an API. Never translate an API from memory, from React, or from an older GPUI example. Kit docs index: `https://gpui-kit.com/llms.txt`; any page is Markdown with `.md` appended. After the first build, the exact source is under `~/.cargo/registry/src/*/gpui-base-0.10.0`, `gpui-component-0.10.0` and `gpui-pre-0.3.12`.
- No taglines or helper text in the interface.
- Every code block in this plan was written from documentation and has not been compiled. If the compiler disagrees, read the source named above, fix the call, and note the correction in the commit message. Do not guess a second time.
- Commit after each task. The repository has no commits yet; work on the current branch.

```rust
use gpui_kit::test::TestWindowExt;
use gpui_kit::{AppContext, Bounds, TestAppContext, WindowBounds, WindowOptions, px, size};
use viewer::{AppView, EXPLORER_WIDTH};

#[gpui_kit::test]
fn window_shows_explorer_left_of_stage(cx: &mut TestAppContext) {
    cx.update(gpui_kit::init);
    let (handle, _view) = cx.update(|cx| {
        gpui_kit::open_window(
            WindowOptions {
                window_bounds: Some(WindowBounds::Windowed(Bounds::new(
                    Default::default(),
                    size(px(1000.), px(700.)),
                ))),
                ..Default::default()
            },
            cx,
            |window, cx| cx.new(|cx| AppView::new(window, cx)),
        )
        .expect("open test window")
    });

    cx.update_window(handle.into(), |_, window, cx| {
        window.render_frame(cx);

        let explorer = window.find("explorer-pane");
        let stage = window.find("stage-pane");

        assert!(explorer.visible());
        assert!(stage.visible());
        // The divider takes a few pixels, so allow a small tolerance.
        let width = explorer.bounds().size.width;
        assert!(width > px(EXPLORER_WIDTH - 12.) && width < px(EXPLORER_WIDTH + 12.));
        assert!(stage.bounds().left() >= explorer.bounds().right());
        assert!(stage.bounds().size.width > px(600.));
    })
    .unwrap();
}
```

- [ ] **Step 4: Write the implementation**

Replace `crates/viewer/src/app.rs`:

```rust
use gpui_kit::component::resizable::{h_resizable, resizable_panel};
use gpui_kit::test::TestSupportExt;
use gpui_kit::{Context, IntoElement, Render, Window, div, prelude::*, px};

/// Starting width of the explorer pane, in pixels.
pub const EXPLORER_WIDTH: f32 = 300.0;

/// The root view: explorer on the left, stage on the right.
pub struct AppView;

impl AppView {
    pub fn new(_window: &mut Window, _cx: &mut Context<Self>) -> Self {
        Self
    }
}

impl Render for AppView {
    fn render(&mut self, _window: &mut Window, _cx: &mut Context<Self>) -> impl IntoElement {
        h_resizable("panes")
            .child(
                resizable_panel()
                    .size(px(EXPLORER_WIDTH))
                    .child(div().id("explorer-pane").test_support().size_full()),
            )
            .child(
                div()
                    .id("stage-pane")
                    .test_support()
                    .size_full()
                    .into_any_element(),
            )
    }
}
```

`gpui_kit::test::TestSupportExt` may exist only when the `test-support` feature is on. If `cargo build -p viewer` reports that `gpui_kit::test` or `test_support` is missing, change the `[dependencies]` line in `crates/viewer/Cargo.toml` to:

```toml
gpui-kit = { workspace = true, features = ["test-support"] }
```

and add this line to the "Known gaps" list in `AGENTS.md` during Task 3: `viewer enables gpui-kit's test-support feature in release builds; revisit when a milestone adds a release profile.`

```rust
use gpui_kit::{AppContext, TitlebarOptions, WindowOptions};
use viewer::AppView;

fn main() {

        .with_assets(gpui_kit::assets::Assets)
        .run(|cx| {

                        ..Default::default()
                    }),
                    ..Default::default()
                },

            )
            .expect("open main window");
        });
}
```
